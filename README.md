# YouTubeコメント分析 — 余白観察室

YouTube動画の公開コメントを取得し、Jevで感情の向き・熱量・好意と批判の混在・文体印象を分析するNext.jsアプリです。revision-04の画面構成とrevision-03の尺度・色定義を実装しています。UIはMaterial UIを使用します。

## 起動

1. `.env.example` を参考に `.env` に `YOUTUBE_DATA_API_KEY` と `TYPESAFE_API_KEY` を設定します。
2. `npm ci`
3. `npm run dev`
4. `http://localhost:3000` を開き、YouTube動画URLを入力します。

「サンプルデータで試す」はAPIキー不要です。設計用の `sample-groups.json` から再構成した架空100コメントを表示し、実際の取得・分類結果とは明示して区別します。プロフィール画像がない場合は人物アイコン、実データの表示名がない場合は「匿名の投稿者」にフォールバックします。

本番モードは `npm run build` の後に `npm start` で起動します。

既存のnpmキャッシュに所有権エラーがある場合は、`npm ci --cache /tmp/jev-npm-cache` で一時キャッシュを利用できます。

## ファビコン・メタデータ

名称・説明文・言語・テーマカラーは `lib/site.ts` で管理し、ページのタイトル、Open Graph / Twitter Card、Web App Manifestで共通利用します。青い吹き出しと分析グラフのアイコンを、タブ・ブックマーク・ホーム画面で使用します。

- `app/icon.svg`：編集用のベクター原稿兼SVGファビコン。
- `app/favicon.ico`：16 / 32 / 48pxの互換用ファビコン。
- `app/apple-icon.png`：180pxのApple用アイコン。
- `app/manifest.ts`、`public/icons/`：ホーム画面向けの名称・配色と192 / 512pxアイコン、512pxのmaskableアイコン。
- `assets/social-card.svg`、`public/social-card.png`：共有用画像の原稿と1200 × 630pxのPNG。

公開するときは `.env` またはホスティング環境で `SITE_URL` に実際のオリジン（例：`https://your-domain.example`）を設定してから `npm run build` を実行してください。canonical、`og:url`、Open Graph / Twitterの画像URLに使用します。パス・クエリ・認証情報を含む値はエラーにします。未設定のローカル利用でも起動でき、仮のURLや画像URLは出力しません。タイトル・説明文・アイコンは常に出力します。

アイコンや共有画像のSVGを編集したら `npm run assets:metadata` で画像を再生成します。共有画像の日本語には、ヒラギノ角ゴまたはNoto Sans CJK JPが必要です。生成済み画像はGit管理するため、通常のビルド時にフォントや画像生成処理は不要です。ホーム画面用メタデータの追加であり、オフライン利用は提供しません。

アイコンとManifestのタグは[Next.jsのファイルベースMetadata API](https://nextjs.org/docs/app/api-reference/file-conventions/metadata)で自動生成します。

## 分析・取得

動画情報を読み込んだ後、件数にかかわらず分析範囲を選択します。「まず100件」（100件未満なら動画全体件数）・「10%」・「25%」・「全件」のクイック選択に加え、任意の件数（1以上の整数）または割合（1〜100%の整数）を入力できます。割合はスライダーでも調整でき、開始前に取得上限を表示します。

割合は確認画面に表示した動画全体の件数を基準に計算し、小数点以下を切り上げます（例：1,234件の10% → 最大124件）。取得は関連度順の先頭からで、ランダムサンプリングではありません。動画全体件数と返信を除く取得可能件数は異なるため、上限に届かない場合も取得できた分を分析します。割合100%は表示件数を上限とし、「全件」は取得可能な全ページを取得します。コメントスレッドの先頭コメントを取得し、返信は含みません。Jevは最大4並列で処理し、成功結果をNDJSONで順次表示します。進捗・経過時間・速度・失敗数・トークン・推定費用を確認できます。失敗したコメントは集計から除き、成功分を残します。

取得の順序と、画面上の並び順は別です。いいね数・投稿日時・平均値・各段階や文体の確率・混在確率で並び替えられます。

## 保存・再ロード

Jevの分析完了時に結果を自動保存します。「保存」でも手動保存でき、途中で通信が切れた場合の成功分やサンプルも残せます。「保存データを開く」から、ページ・サーバーを再起動した後も再取得・再分析なしで復元できます。保存対象は絞り込み前の全分析済みコメントです。保存エラー時は画面に成功分を残し、手動で再試行できます。

保存先はアプリを起動したサーバーの `.data/analyses/<UUID>.json`（Git管理対象外）。JSONの書き出し・読み込みもできます。読み込んだJSONを履歴へ残すには「保存」を押してください。ローカル運用ではこのPCに保存されます。別サーバーへ移す場合はJSONを移行し、永続ディスクのない実行環境では別途永続ストレージが必要です。

- **`schemaVersion: 1`**：ファイル構造の互換性を管理。未対応版や破損データは明示的に拒否し、表示中の結果を保持します。
- **保存日時・分析開始/完了日時**、動画情報、コメント原文・投稿者名・投稿日時・取得時のいいね数、全確率分布を保持。
- **分析条件**：取得範囲（任意件数・割合とその基準件数・全件。旧形式の先頭100件も読込可能）、関連度順、返信除外、成功/失敗/対象件数、完了/途中の状態、処理時間・トークン・推定費用を保持。
- **判定の追跡情報**：モデル名、`definitionVersion`、質問と尺度アンカーのSHA-256、アプリバージョン。`GIT_COMMIT` または `VERCEL_GIT_COMMIT_SHA` が設定されていればコミットハッシュも記録します。コミットは互換性判定には使いません。モデル名が可変エイリアスの場合、サービス内部の厳密なモデル版の再現は保証しません。
- **画像**：投稿者画像と動画サムネイルのURLは保存せず、復元時は省略します。APIキーも保存しません。

保存時刻は保存操作の日時、分析日時は元の判定日時です。再保存しても分析日時は引き継ぎます。サンプルは実分析日時と判定定義ハッシュを持たず、履歴でも区別します。

## 画面と共通条件

- **コメント**：投稿者情報、日時、いいね、小グラフ、文体バッジを揃えた固定高の行。本文は2行までで、ダイアログでは全文の直後に確率分布を続けて表示します。一覧上部に高さ340pxの「感情の向き × 熱量」マップと感情構成を表示し、点のホバーやキーボードフォーカスで本文の抜粋・感情・熱量・いいね・混在確率を確認でき、クリックすると同じ詳細を開けます。マップは開閉でき、重なる点はメニューから選べます。1ページ6件です。
- **性別・年代別**：共通件数軸による比較グラフと、カテゴリ座標による性別×年代マップ。グループ選択はプレビューで、「このN件をコメントで見る」で初めて条件を絞り込みます。「元の比較条件に戻る」で元の対象へ復帰します。
- **性別**：3区分のチェックはOR。全解除は0件。「全選択」で復帰できます。
- **年代**：5カテゴリの両端を含む範囲。2つのハンドルは交差せず、同一カテゴリだけを選ぶこともできます。矢印キーで操作できます。
- **共有**：性別・年代、検索、感情、熱量はAND。タブ・グラフ切り替えで条件を保持します。検索・感情・熱量・並び順はコメント側で編集し、他の画面にも同じ対象を渡します。条件変更でAPIを再実行しません。
- **リセット**：「性別・年代をリセット」はその2条件だけを戻します。検索・感情・熱量は残ります。

絞り込み編集は通常折り畳み、対象件数と条件要約を表示します。グラフの分母は分析済みの対象コメントであり、動画全体件数や人数ではありません。

## 尺度と読み方

感情は5段階のアンカー `[-2,-1,0,+1,+2]`、熱量は `[0,1,2,3,4]` の確率加重平均です。

- 感情 −0.5未満は批判寄り `#BA6559`、−0.5〜+0.5は中央帯 `#87919A`、+0.5超は好意寄り `#438575`。
- 熱量は0〜4の固定尺度と `#B28E54`。独自の低・中・高の分類は追加しません。
- 好意と批判の混在はNoul命題の確率。0〜100%と `#8E82AE`。本文中の感情割合や正答率ではありません。
- 混在確率50%以上を「好意と批判の両方を含むコメント（推定）」として独立集計し、該当原文に絞り込めます。50%は集計の基準であり、文章内の感情割合ではありません。感情マップでは紫枠で示します。
- 感情マップの円は取得時のいいね数に面積比例（半径は平方根）。0件・少数にも半径3pxの最小サイズを設け、最大15px。同じ分析内では絞り込み後も全件の最大いいね数を尺度に使います。
- 中央帯±0.5はアンカー−1・0・+1の中点による表示上の区分で、統計的に中立を保証する閾値ではありません。好意・批判が相殺された平均も中央帯に入るため、確率分布や混在推定と併せて読みます。
- 中央80%区間は段階分布の10〜90%点。Jev confidenceは確率・正答率とは異なる指標です。
- 性別×年代マップは円全体の面積が件数に比例します。中央の色は平均値−2〜+2を赤→淡い灰色→緑の連続色で表し、外周リングは批判寄り・中央帯・好意寄りのコメント割合を表します。同じ平均0でも、中央帯中心と批判・好意の相殺を区別できます。外周はコメント間の構成であり、1コメント内の混在確率とは別です。範囲外・選択外には点を描かず、0件と区別します。

年代の最下位区分は「小学生以下」です。保存互換性のため内部キー `pre_elementary` は維持し、新しいJev判定文言は小学生を含めます。既存の保存結果を再判定することはありません。判定文言の変更は定義ハッシュに反映されます。

**文体印象は本人の年齢・性別ではありません。** カテゴリ間の距離は実年齢の差を示しません。

## 構成

- `app/page.tsx`：取得・分析ストリーム、画面と共通状態の管理
- `components/comment-scope-dialog.tsx`、`lib/comment-scope.ts`：取得範囲のガイドUI・入力検証・上限計算
- `components/common-filters.tsx`：共通フィルター
- `components/comment-overview.tsx`：感情の向き×熱量マップ・対象の感情構成
- `components/comments-view.tsx`：コメント・分析詳細
- `components/analysis-library.tsx`：保存履歴・JSON入出力・自動保存
- `components/demographics.tsx`：比較・性別×年代マップ
- `lib/analysis.ts`：尺度・色・集計・絞り込み・ソート
- `lib/sentiment-display.ts`：平均の連続色・感情構成リングの割合
- `lib/analysis-archive.ts`、`lib/analysis-store.ts`：保存スキーマ・検証・ファイル永続化
- `app/api/analyses/`：保存・履歴・復元API
- `lib/youtube.ts`、`lib/jev.ts`：既存の外部API接続

Material UIは[公式Next.js統合](https://mui.com/material-ui/integrations/nextjs/)に沿ってApp Router用キャッシュプロバイダーを使用します。開発出力は `.next-dev`、本番ビルドは `.next` に分けています。Next.jsが使用するPostCSSは修正版へoverrideしています。
